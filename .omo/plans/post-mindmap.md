## Context

### Original Request

User wants a collapsible mindmap for each blog post that:

- Shows the argument flow (thesis → supporting arguments → evidence)
- Renders as interactive SVG in-page with dark/light theme support
- Has a subtle toggle below the title (icon + "View mindmap")
- Doubles as the OG image for social sharing (dark background PNG)
- Is generated by AI (OpenRouter frontier model) via a local script
- No commits/pushes until the feature is nailed down

### Interview Summary

**Key Discussions**:

- **Mindmap content**: Argument flow style (central thesis → supporting arguments → key evidence). Compact: 5-8 nodes.
- **OG image**: Dark background (dark gray/black + terminal green nodes), 1200×630px PNG.
- **Toggle**: Inline subtle below title, smooth expand animation, icon-based.
- **SVG→PNG**: resvg-js (Rust/WASM, no browser dependency).
- **Generation**: Full auto, regenerate anytime. No manual editing needed.
- **Model config**: Both `OPENROUTER_API_KEY` and `OPENROUTER_MODEL` in `.env` file (not hardcoded).
- **API key**: Already configured locally.

**Research Findings**:

- `scripts/generate-audio.mjs` is the perfect precedent: read MDX → strip text → call API → produce asset → update frontmatter. Uses `gray-matter`.
- `PostLayout.tsx` has clear insertion point between header (lines 36-50) and content (lines 76-89).
- `InlineAudio.tsx` has reusable collapsible toggle pattern (useState + conditional render + aria-expanded).
- `contentlayer.config.ts` already has `images` field (json). We'll add a dedicated `mindmap` field.
- OG flow: `app/blog/[...slug]/page.tsx` reads `post.images` → generates og:image meta.
- Color tokens: primary-50 to 950 (terminal green OKLCH), gray-50 to 950.
- Dark mode: `.dark` class via `next-themes`, `dark:` Tailwind prefix.
- Husky configured but `.env` is NOT in `.gitignore` — security fix needed.
- 12 existing posts, none have images currently.

### Metis Review

**Identified Gaps** (addressed):

- **Source of truth**: AI returns structured JSON graph, NOT raw SVG. Local code renders both SVG and PNG from the same data.
- **OG precedence**: Use dedicated `mindmap` frontmatter field to store SVG path. OG image path derived from slug convention, not overwriting `images`.
- **Failure policy**: Fail-open. API errors skip post with warning, never corrupt frontmatter, never block commits.
- **Schema validation**: Strict JSON schema validation before any file writes. Reject malformed AI output.
- **Idempotency**: Rerunning on unchanged content produces zero diff.
- **Pre-commit scoping**: Process only staged/changed blog MDX files, not all posts.
- **Font consistency**: Use system monospace fonts (JetBrains Mono) that match the blog theme for both SVG and PNG rendering.
- **`.env` security**: `.env` contains API key but is NOT in `.gitignore` — must fix.
- **Draft posts**: Skip drafts (matches generate-audio.mjs behavior).
- **Accessibility**: Button with `aria-expanded`, `aria-label`, SVG with `role="img"` + descriptive `aria-label`.

# Learnings - Audio Text Highlight Sync

## 2026-03-10: ElevenLabs /with-timestamps Endpoint

### API Endpoint

- URL: `POST /v1/text-to-speech/{voice_id}/with-timestamps`
- Accept header: `application/json` (not `audio/mpeg`)
- Returns JSON with base64 audio and word-level timestamps

### Response Format

```json
{
  "audio": "base64_encoded_audio",
  "text": "original text",
  "meta": {
    "timestamp": [{ "text": "word", "start": 0.123, "end": 0.456 }]
  }
}
```

### Timestamp Storage

- MP3: `https://audio.adaofeliz.com/{slug}.mp3`
- JSON: `https://audio.adaofeliz.com/{slug}-timestamps.json`
- Frontmatter fields: `audio`, `audioTimestamps`

### Timestamp JSON Format

```json
{
  "version": 1,
  "words": [{ "word": "Hello", "start": 0.0, "end": 0.5 }],
  "sourceText": "original text"
}
```

## 2026-03-10: AudioHighlightContext Implementation

### Timestamp Data Structure

- Format: `{ version: number, words: { word: string, start: number, end: number }[], sourceText: string }`
- Generated by `scripts/generate-audio.mjs` using ElevenLabs API
- Stored as JSON at `https://audio.adaofeliz.com/{slug}-timestamps.json`

### Binary Search Optimization

- Start from last known index (likely nearby for forward playback)
- Check next word first (forward progression is most common case)
- Fall back to full binary search if optimization misses

### requestAnimationFrame Pattern

- Use ref for currentTime to avoid stale closure in animation frame callback
- Cancel animation frame on cleanup
- Only run animation frame loop while `isPlaying` is true
- Separate useEffect for seeking (currentTime changes while paused)

### TypeScript Narrowing in Async Functions

- TypeScript doesn't narrow types inside nested async functions
- Solution: capture value in local const before async function definition
- Example: `const url = timestampUrl` before `async function fetchTimestamps()`

## 2026-03-10: HighlightableContent Component

### TreeWalker API for DOM Text Node Traversal

- Use `document.createTreeWalker(container, NodeFilter.SHOW_TEXT, { acceptNode })` to efficiently find text nodes
- `acceptNode` callback can return `NodeFilter.FILTER_REJECT` to skip entire subtrees
- Check parent chain to skip `<pre>`, `<code>`, and `data-no-highlight` elements

### Word Wrapping Strategy

- Split text with `text.split(/(\s+)/)` to preserve whitespace as separate fragments
- Whitespace fragments kept as text nodes (no wrapping)
- Word fragments wrapped in `<span class="audio-word" data-word-index={i}>`
- Track word index globally across all text nodes to match timestampData.words

### Direct DOM Manipulation for Performance

- Use `useRef` to track last active word index
- On `activeWordIndex` change, use `querySelector` with `data-word-index` attribute
- `classList.add/remove('audio-word-active')` for highlighting
- Avoid React re-renders - direct DOM updates only

### Graceful Degradation

- Check `context?.timestampData?.words?.length` before wrapping
- If no context or no timestamp data, render children normally
- Use `isWrappedRef` to prevent double-wrapping on re-renders
